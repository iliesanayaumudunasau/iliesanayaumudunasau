Wireframe

A barber shop wireframe is a detailed line drawing that outlines the layout and structure of a barbershop interior, It typically includes elements like barber chairs, mirrors, counters with grooming tools, waiting areas, and decorative features — all shown in a clean, minimalist style to visualize spatial arrangement and design flow.
